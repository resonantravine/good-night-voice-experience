# Cola MODs

## Good Night Mode

A low-stimulation bedtime persona for Cola. Instead of engaging, it gradually withdraws — helping the user let go of the day and move toward sleep.

Based on the [Good Night voice interaction study](https://github.com/resonantravine/good-night-voice-experience).

## Install

```bash
cp -r mods/good-night ~/.cola/mods/
```

Then say "切换到 good night mode" in Cola.
